## Orphan prevention

- Every normative `.neu` and vocabulary JSON fixture is named by the
  conformance manifest; every registered path must exist.
- Every TOML oracle beneath `portable/conformance/oracles` is named by the
  conformance manifest and exercised by its owning conformance test group.
- Compiler, encoding, and probe diagnostics are centralized public constants;
  negative conformance and hostile-decoder tests compare their stable codes.
- `missing_docs`, private-item documentation, rustdoc link checks, Clippy, and
  doc tests cover public and private API documentation.
- `cargo xtask traceability check` enforces ID coverage, completed master items,
  fixture/oracle inventory, and registered-path integrity. `cargo xtask ci pr`
  and `cargo xtask ci release` both run it.
