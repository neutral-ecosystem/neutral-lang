# Portable validation evidence

This directory contains concise reviewed records for completed portable-plan
gates. Raw command output remains generated under `test-results/`; these
records identify the stable commands, durable inputs, result, and limitations
needed to understand why a checklist item is complete.

Evidence here describes future-version development gates. Released language
contracts and release evidence remain under `conformance/releases/` and
`quality/evidence/` respectively.
