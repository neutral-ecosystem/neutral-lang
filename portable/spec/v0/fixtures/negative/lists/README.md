# Negative ordered-list fixtures

This directory freezes Slice 4.3 failures for heterogeneous items, malformed
delimiters, and item, nesting, and traversal resource limits.

Within the ecosystem each immutable source owns an exact failure boundary in
the Stage 4 oracle set and proves that bounded parsing fails before unbounded
list allocation.
