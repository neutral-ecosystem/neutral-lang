# Historical project capture records

This directory preserves earlier reviewed capture requests and fixture bytes.
It has no registered executable Rust module. Its presence does not prove current
request, lock, closure, limit or determinism behavior.

Current capture checks run in `neutral-compiler/tests/expression_source/capture.rs`,
`capture_limits.rs`, `project_capture_contract.rs`, and the sibling
`composition_contract/capture.rs` and expression/source pipeline modules.
See the [active test inventory](../README.md). Historical inputs stay in place;
they are not a fallback acceptance path.
