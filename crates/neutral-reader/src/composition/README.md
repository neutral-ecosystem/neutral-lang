# Composition reader traversal

The parent composition API inspects separately validated vocabulary catalogues.
This module owns bounded public reference-type dependency enumeration without
compiler linkage, source reparsing, private provenance, or target acquisition.
It is not the project codec/probe activation boundary. Target type contracts are
data; enumerating them does not resolve a source binding or grant execution.
